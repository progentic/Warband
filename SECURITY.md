# Security Policy

Warband is not yet a production runtime. Phase 1 adds a deterministic foundation CLI and build/verification tooling. Authoritative execution, provider access, persistence, and deployment remain unavailable.

Security issues in the documentation still matter. Report problems such as:

- unclear trust boundaries;
- contradictory security guarantees;
- missing failure behavior;
- unsafe approval rules;
- weak audit requirements;
- documentation that permits model output to bypass policy or verification.

Do not publish sensitive vulnerability details in a public issue. Use the repository's private security reporting channel when one is available.
