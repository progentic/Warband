# Non-Goals

This document prevents the project from expanding before the core safety boundary is proven.

The initial Warband runtime will not provide:

- unrestricted autonomous execution;
- arbitrary shell access;
- broad network access;
- self-modifying policy;
- model-authored security rules;
- automatic promotion of learned patterns;
- unsupervised irreversible actions;
- distributed consensus;
- general-purpose multi-agent collaboration;
- guarantees that external systems behave deterministically;
- a web interface before the runtime boundary is stable.

These features may be considered later. They are not part of the initial architecture baseline.
