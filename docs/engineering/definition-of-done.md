# Definition of Done

A Warband feature is complete only when:

1. The user behavior is documented.
2. The engineering boundary is documented.
3. The security guarantee is documented.
4. The verification method exists.
5. Positive tests pass.
6. Negative-path tests pass.
7. Audit events are defined.
8. Errors are safe and documented.
9. Compatibility and migration effects are addressed.
10. The traceability record is updated.
11. No higher-authority document is contradicted.
12. Maintainer ownership is assigned.

Compiling code is necessary. It is not sufficient.
